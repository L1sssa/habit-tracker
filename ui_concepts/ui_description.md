## Как создавались концепции

Для генерации UI-концепций использовался **v0.dev** (Text-to-UI инструмент от Vercel). Промпты формулировались по структуре RTCF:

Role: UI/UX Designer
Task: Сгенерировать интерфейс Habit Tracker в стиле [стиль]
Context: Приложение для отслеживания привычек. Основные элементы: список привычек, форма добавления, streak, кнопки отметки.
Format: Скриншот + экспорт кода.

Сгенерированы **3 концепции**, отличающиеся по стилю и компоновке.

## Концепция 1. Минималистичная

**Стиль:** Clean / Minimalist
**Цветовая палитра:** Белый фон, чёрный текст, акцент — голубой (#007BFF).
**Шрифт:** System UI, sans-serif.

**Ключевые особенности:**

- Много свободного пространства (whitespace).
- Тонкие линии и границы.
- Крупные отступы между элементами.
- Одна колонка, центрированная.
- Streak отображается маленьким бейджем рядом с названием.

**Компоновка:**

- Сверху — заголовок «Habit Tracker».
- Ниже — форма добавления привычки (одна строка: input + выбор цвета + кнопка).
- Далее — вертикальный список карточек привычек.
- В каждой карточке: название, streak, кнопки «Отметить» и «Удалить».

**Преимущества:**
- Легко читается.
- Не отвлекает.
- Хорошо работает на мобильных.

**Недостатки:**
- Мало визуальных акцентов.
- Может показаться скучным.

---

## Концепция 2. Яркая и игровая (Gamified)

**Стиль:** Playful / Gamified
**Цветовая палитра:** Яркие цвета (жёлтый, розовый, зелёный, фиолетовый).
**Шрифт:** Rounded sans-serif (например, Nunito).

**Ключевые особенности:**

- Каждая привычка имеет свой цвет.
- Streak показан крупно, с иконкой огня 🔥.
- Прогресс визуализирован через progress bar.
- Анимация при отметке (конфетти).
- Иконки для каждой привычки (эмодзи).

**Компоновка:**

- Верх — крупный заголовок с общим streak.
- Ниже — сетка карточек (grid, 2–3 в ряд на десктопе, 1 на мобильном).
- В каждой карточке: крупный эмодзи, название, progress bar, кнопка «Отметить».
- Внизу — плавающая кнопка «+» для добавления.

**Преимущества:**
- Мотивирует через визуализацию.
- Подходит для мобильных.
- Игровой элемент повышает вовлечённость.

**Недостатки:**
- Может отвлекать.
- Сложнее в реализации.

## Концепция 3. Корпоративная / Дашборд

**Стиль:** Corporate / Dashboard
**Цветовая палитра:** Серый, белый, синий (#2C3E50, #3498DB).
**Шрифт:** Inter / Roboto.

**Ключевые особенности:**

- Данные представлены в виде таблицы.
- Сверху — статистика (общее число привычек, средний streak, процент выполнения).
- Слева — список привычек.
- Справа — детали выбранной привычки (календарь, история).
- Строгий, деловой стиль.

**Компоновка:**

- Хедер с навигацией.
- Панель статистики (3–4 карточки с метриками).
- Таблица привычек: название, streak, последняя отметка, действия.
- Боковая панель с деталями.

**Преимущества:**
- Много информации на одном экране.
- Подходит для «продвинутых» пользователей.
- Легко масштабируется (аналитика, отчёты).

**Недостатки:**
- Перегружен для новичков.
- Плохо работает на мобильных.

## Выбор концепции

**Выбрана: Концепция 1 (Минималистичная) с элементами Концепции 2.**

**Обоснование:**

1. **Простота реализации.** Проект — учебный, важно уложиться в сроки. Минимализм проще сверстать, чем дашборд или анимации.

2. **Адаптивность.** Минималистичная концепция легко адаптируется под мобильные — одна колонка, крупные элементы.

3. **Фокус на главном.** Основная задача — быстро добавить привычку и отметить её. Минимализм не отвлекает.

4. **Элементы из Концепции 2.** Streak будет показан с иконкой 🔥 (как в яркой концепции), чтобы добавить мотивации.

5. **Концепция 3 (дашборд)** — слишком сложна для MVP, но её элементы (статистика) можно добавить в будущих версиях.

## Итоговая концепция

**Стиль:** Минимализм + игровые элементы.
**Цвета:** Белый фон, чёрный текст, акцент — голубой (#007BFF), streak — оранжевый (#FF6B35).
**Шрифт:** System UI.

**Компоновка:**

- Заголовок «Habit Tracker».
- Форма добавления (одна строка).
- Список карточек привычек (вертикальный).
- В каждой карточке: название, streak с иконкой 🔥, кнопки «Отметить» и «Удалить».

**Адаптивность:**
- Десктоп: карточки в одну колонку с большими отступами.
- Мобильные: карточки растягиваются на всю ширину.
