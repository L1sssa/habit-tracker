# Описание проекта — Habit Tracker

## 1. Основная идея

**Habit Tracker** — это веб-приложение для отслеживания ежедневных привычек. Пользователь создаёт список полезных и вредных привычек (зарядка, прогулка, чтение, курение, алкоголь), отмечает их выполнение каждый день и видит свой прогресс через streak (серию дней), статистику и календарь.

## 2. Проблема, которую решает приложение

**Проблема:** людям сложно формировать полезные привычки и избавляться от вредных, потому что:
- Нет наглядной картины прогресса.
- Сложно отслеживать, сколько дней подряд удаётся держаться.
- Забывается мотивация после нескольких срывов.

**Решение:** приложение даёт:
- Простой интерфейс для ежедневных отметок.
- Визуализацию streak — серии успешных дней.
- Статистику за неделю/месяц.
- Поддержку как полезных, так и вредных привычек (для отслеживания отказа).

## 3. Целевая аудитория

| Сегмент | Описание |
|---------|----------|
| Основной | Люди 18–45 лет, интересующиеся саморазвитием |
| Вторичный | Люди, бросающие вредные привычки (курение, алкоголь) |
| Третичный | Студенты и офисные работники, желающие структурировать день |

**Портрет типичного пользователя:**
- Возраст: 20–40 лет.
- Использует смартфон и ноутбук.
- Хочет формировать 2–5 привычек одновременно.
- Ценит простоту и наглядность.

## 4. Ключевые функции (MVP)

Минимум 3 функции, но мы реализуем 5:

1. **Добавление привычки**
   - Пользователь вводит название (например, «Зарядка»).
   - Выбирает цвет для визуализации.
   - Выбирает тип: полезная / вредная.

2. **Список привычек**
   - Отображается список всех привычек.
   - Для каждой видна иконка, название, streak.
   - Кнопки «Отметить» и «Удалить».

3. **Ежедневная отметка**
   - Пользователь нажимает «Отметить» — привычка считается выполненной за сегодня.
   - Повторное нажатие снимает отметку.
   - Streak пересчитывается автоматически.

4. **Streak (серия дней)**
   - Для каждой привычки показывается количество дней подряд.
   - Если пропущено 2+ дня — серия сбрасывается.

5. **Статистика (в планах)**
   - Процент выполнения за неделю/месяц.
   - Календарь выполненных дней.

## 5. Ценность приложения

| Для пользователя | Для разработчика |
|------------------|------------------|
| Наглядный прогресс | Простой стек (React + TypeScript) |
| Простой интерфейс | Возможность расширения (Supabase, аналитика) |
| Мотивация через streak | Учебный проект для отработки AI-разработки |
| Поддержка полезных и вредных привычек | Чистая архитектура |

## 6. Примеры привычек

**Полезные:**
- Утренняя зарядка
- Прогулка 30 минут
- Чтение 20 страниц
- Медитация
- Пить 2 литра воды

**Вредные (отслеживание отказа):**
- Курение
- Алкоголь
- Сладкое
- Соцсети

## 7. Ограничения и допущения

- **MVP:** данные хранятся в localStorage (без синхронизации).
- **Backend (в планах):** Supabase (PostgreSQL).
- **Авторизация:** в MVP отсутствует, в планах — OAuth2.
- **Язык интерфейса:** русский.
- **Платформа:** веб (десктоп + мобильные браузеры).

## 8. Метрики успеха

- Пользователь может добавить привычку за ≤ 10 секунд.
- Отметка выполнения — в 1 клик.
- Streak отображается корректно на всех устройствах.
- Приложение работает без ошибок в браузере.
