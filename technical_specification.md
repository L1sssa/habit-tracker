---

## 1. Описание проекта

**Habit Tracker** — веб-приложение для отслеживания ежедневных привычек. Пользователь создаёт список привычек (полезных и вредных), отмечает их выполнение каждый день и видит прогресс через streak, статистику и календарь.

**Цель:** помочь пользователю формировать полезные привычки и избавляться от вредных через простой и наглядный интерфейс.

**Платформа:** веб (десктоп + мобильные браузеры).

**Язык интерфейса:** русский.

---

## 2. Целевая аудитория

**Основной сегмент:** люди 18–45 лет, интересующиеся саморазвитием.

**Персоны:**

1. **Анна, 28 лет** — молодой специалист, хочет формировать полезные привычки. Ценит простоту.
2. **Дмитрий, 35 лет** — бросает курить. Ценит мотивацию и крупный streak.
3. **Мария, 22 года** — студентка, отслеживает 5 привычек одновременно. Ценит наглядность.

## 3. Функциональные требования

### 3.1. FR-01. Добавление привычки

**Описание:** пользователь может добавить новую привычку.

**Поля формы:**
- Название (обязательное, до 50 символов).
- Цвет (обязательное, выбор из палитры).
- Тип: полезная / вредная (обязательное).

**Поведение:**
- Валидация названия (не пустое, до 50 символов).
- Проверка на дубликаты (предупреждение, но создание разрешено).
- После сохранения — привычка появляется в списке.

**Связанные US:** US-01, US-06.

---

### 3.2. FR-02. Просмотр списка привычек

**Описание:** пользователь видит все свои привычки.

**Отображение:**
- Список карточек, по одной в строке.
- В каждой карточке: название, streak с иконкой 🔥, кнопки «Отметить» и «Удалить».
- Цвет карточки соответствует выбранному цвету привычки.
- Тип (полезная / вредная) отображается цветным индикатором.

**Поведение:**
- Если список пуст — сообщение «Нет привычек. Добавьте первую!».
- Список сортируется по дате создания (новые сверху).

**Связанные US:** US-02.

---

### 3.3. FR-03. Ежедневная отметка

**Описание:** пользователь может отметить привычку выполненной за сегодня.

**Поведение:**
- Кнопка «Отметить» меняет состояние на «Отмечено».
- Повторное нажатие снимает отметку.
- Streak пересчитывается автоматически.
- Отметка сохраняется в localStorage.

**Связанные US:** US-03, US-04.

---

### 3.4. FR-04. Streak (серия дней)

**Описание:** для каждой привычки отображается количество дней подряд.

**Правила расчёта:**
- Streak считается с сегодняшнего дня назад.
- Если сегодня отмечено — streak увеличивается.
- Если вчера отмечено, а сегодня нет — streak продолжается (льготный день).
- Если пропущено 2+ дня — streak сбрасывается в 0.

**Связанные US:** US-04.

---

### 3.5. FR-05. Удаление привычки

**Описание:** пользователь может удалить привычку.

**Поведение:**
- Кнопка «Удалить» в карточке.
- Диалог подтверждения: «Удалить привычку?».
- После подтверждения — привычка исчезает из списка.
- Отмена — привычка остаётся.

**Связанные US:** US-05.

---

### 3.6. FR-06. Тип привычки (полезная / вредная)

**Описание:** пользователь указывает тип при создании.

**Отображение:**
- Полезная — зелёный индикатор.
- Вредная — красный индикатор.

**Связанные US:** US-06.

---

### 3.7. FR-07. Статистика за неделю

**Описание:** пользователь видит процент выполнения за неделю.

**Поведение:**
- Расчёт: количество отмеченных дней / 7 * 100%.
- Отображение: «X% за неделю».
- Если нет данных — «Нет данных за неделю».

**Связанные US:** US-07.

## 4. Нефункциональные требования

### 4.1. NFR-01. Производительность

- Загрузка приложения: ≤ 2 секунд.
- Отметка привычки: ≤ 100 мс.
- Работа без лагов при 100+ привычках.

### 4.2. NFR-02. Безопасность

- Данные хранятся локально (localStorage) в MVP.
- В планах: Supabase с RLS-политиками.
- Никаких секретов в коде.
- Валидация пользовательского ввода.

### 4.3. NFR-03. Адаптивность

- Десктоп: 1024px+.
- Планшет: 768–1024px.
- Мобильные: 320–768px.
- Одна колонка на мобильных, две — на десктопе.

### 4.4. NFR-04. Доступность

- Контраст текста: WCAG AA.
- Кликабельные элементы: ≥ 44x44px.
- Поддержка клавиатуры: Tab, Enter, Escape.

### 4.5. NFR-05. Совместимость

- Chrome 90+, Firefox 88+, Safari 14+, Edge 90+.
- Мобильные браузеры: Chrome, Safari, Firefox.

### 4.6. NFR-06. Поддерживаемость

- Код на TypeScript (строгая типизация).
- Архитектура: компонентная.
- Тесты: Vitest + React Testing Library.
- Линтер: ESLint.

## 7. Обработка ошибок

### 7.1. Ошибки валидации

| Ситуация | Сообщение |
|----------|-----------|
| Пустое название | «Введите название привычки» |
| > 50 символов | «Максимум 50 символов» |
| Дубликат | «Такая привычка уже есть» |

### 7.2. Отсутствие данных

| Ситуация | UX-решение |
|----------|------------|
| Пустой список | «Нет привычек. Добавьте первую!» |
| Нет отметок | «Нет данных за неделю» |

### 7.3. Сетевые ошибки (в планах)

| Ситуация | UX-решение |
|----------|------------|
| 500 | «Что-то пошло не так. Попробуйте позже» |
| Нет интернета | «Нет подключения. Данные сохранены локально» |

### 7.4. Граничные случаи

| Ситуация | UX-решение |
|----------|------------|
| Отметка в 23:59 | Считать текущим днём |
| Смена часового пояса | Пересчёт по локальному времени |
| Удаление последней привычки | «Нет привычек» |
