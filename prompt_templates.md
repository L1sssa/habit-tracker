# Библиотека промпт-шаблонов (prompt_templates.md)

**Проект:** habit-tracker
**Автор:** Елизавета Потапова
**Дата:** 16.10.2026
**Структура шаблонов:** RTCF (Role — Task — Context — Format)

---

## Как пользоваться шаблонами

1. Скопируй нужный шаблон.
2. Замени плейсхолдеры в квадратных скобках на свои значения.
3. Вставь готовый промпт в Cline.

---

## Шаблон 1. Генерация компонента по описанию

**Role:** Senior React Developer
**Task:** Создать компонент по описанию
**Context:** Стек, существующие компоненты, требования к пропсам
**Format:** Полный код файла с указанием пути, типизацией и стилями

### Шаблон

Role: Senior React Developer
Task: Создай компонент [ИМЯ_КОМПОНЕНТА].
Context:
- Проект: React 18 + TypeScript + Vite + date-fns.
- Пропсы: [ПРОПС_1]: [ТИП], [ПРОПС_2]: [ТИП].
- Функциональность: [ОПИСАНИЕ].
Format:
- Полный код файла.
- Путь в комментарии первой строкой.
- Типизация через interface.

### Пример использования

**Задача:** Создать компонент HabitCard.

**Промпт:**

Role: Senior React Developer
Task: Создай компонент HabitCard.
Context:
- Пропсы: habit: Habit, onToggle: (id: string) => void, onDelete: (id: string) => void.
- Функциональность: отображает название, streak, кнопки «Отметить» и «Удалить».
- Использовать calculateStreak из src/utils/streakUtils.ts.
Format:
- Полный код HabitCard.tsx и HabitCard.css.
- Типизация через interface HabitCardProps.

## Шаблон 2. Рефакторинг кода

**Role:** Senior React Developer (Refactoring Specialist)
**Task:** Улучшить существующий код без изменения поведения
**Context:** Текущий код, цели рефакторинга
**Format:** Полный обновлённый код + список изменений

### Шаблон

Role: Senior React Developer (Refactoring Specialist)
Task: Проведи рефакторинг кода ниже.
Context:
- Текущий код:
  [КОД]
- Цели: [ЦЕЛЬ_1], [ЦЕЛЬ_2].
- Поведение НЕ должно измениться.
Format:
- Полный обновлённый код.
- Список изменений.

### Пример использования

**Задача:** Вынести расчёт streak в утилиту.

**Промпт:**

Role: Senior React Developer (Refactoring Specialist)
Task: Проведи рефакторинг HabitCard.
Context:
- Текущий код: [код с inline-расчётом streak]
- Цели: добавить типизацию, вынести calculateStreak в utils.
Format:
- Полный код HabitCard.tsx и streakUtils.ts.
- Список изменений.

**Role:** QA Engineer
**Task:** Написать тесты для существующего кода
**Context:** Компонент, фреймворк, что покрыть

Context:

- Файл [ИМЯ].test.tsx.

**Промпт:**

## Шаблон 4. Исправление ошибок

**Role:** Senior Debugging Engineer
**Task:** Найти и исправить баг
**Context:** Описание ошибки, код, ожидаемое поведение
**Format:** Исправленный код + объяснение

### Шаблон

Role: Senior Debugging Engineer
Task: Исправь ошибку в [ФАЙЛ].
Context:
- Ошибка: [ТЕКСТ].
- Код: [КОД].
- Ожидаемое поведение: [ОПИСАНИЕ].
Format:
- Исправленный код.
- Объяснение причины.

### Пример использования

**Задача:** Исправить Cannot read property 'map' of undefined.

**Промпт:**

Role: Senior Debugging Engineer
Task: Исправь ошибку в HabitList.
Context:
- Ошибка: Cannot read property 'map' of undefined.
- Код: habits.map(...).
- Ожидаемое: если habits undefined — показать «Нет привычек».
Format:
- Исправленный код HabitList.tsx.
- Объяснение причины.

## Шаблон 5. Декомпозиция сложной задачи

**Role:** Tech Lead
**Task:** Разбить задачу на подзадачи
**Context:** Описание задачи, ограничения
**Format:** Список подзадач с оценкой сложности

### Шаблон

Role: Tech Lead
Task: Разбей задачу «[НАЗВАНИЕ]» на подзадачи.
Context:
- Задача: [ОПИСАНИЕ].
- Ограничения: [ОГРАНИЧЕНИЯ].
Format:
- 3-7 подзадач.
- Для каждой: название, описание, S/M/L, зависимости.

### Пример использования

**Задача:** Статистика привычек.

**Промпт:**

Role: Tech Lead
Task: Разбей задачу «Реализовать статистику привычек» на подзадачи.
Context:
- Задача: процент выполнения за неделю и месяц.
- Ограничения: date-fns, без новых зависимостей.
Format:
- 3-7 подзадач с оценкой S/M/L.

## Итог

Библиотека содержит 5 шаблонов:
1. Генерация компонента

3. Написание тестов
